# Dealership terms

| Term               | Meaning in TrailerDesk                                                              |
| ------------------ | ----------------------------------------------------------------------------------- |
| VIN                | Vehicle identification number used to identify a trailer.                           |
| Stock number       | The dealership's own inventory reference. Unique within that dealership.            |
| GVWR               | Gross vehicle weight rating: maximum loaded weight specified by the manufacturer.   |
| Gooseneck          | A hitch that connects to a ball in a truck bed.                                     |
| Bumper pull        | A trailer that attaches to a hitch behind the tow vehicle.                          |
| Fifth wheel        | A hitch with a kingpin and plate in a truck bed.                                    |
| Ramp door          | A rear door that lowers to form a loading ramp.                                     |
| Barn doors         | Rear doors that swing open.                                                         |
| Days on lot        | Calendar time since a trailer arrived at the dealership.                            |
| Hold               | A temporary reservation for one customer, normally 48 hours.                        |
| Lead               | A potential sale that staff can follow through New, Contacted, Quoted, Won or Lost. |
| Quote              | An itemized offer with trailer price, extras, fees, trade-in and tax.               |
| Doc fee            | The dealership's document preparation charge.                                       |
| Trade-in allowance | Credit offered for a customer's existing trailer or vehicle.                        |
| Bill of sale       | The document recording the completed sale.                                          |
| Dealer cost        | Internal acquisition cost, visible only to Owners and Managers.                     |
| Margin             | Difference between sale proceeds and dealer cost.                                   |
| Aging inventory    | Trailers reaching configured age milestones, by default 60, 90 and 120 days.        |
| Stale lead         | A lead with no recent activity, by default for at least 14 days.                    |
