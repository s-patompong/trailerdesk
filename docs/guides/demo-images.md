# Demo inventory images

These seven original photorealistic images were generated with the built-in imagegen tool on 2026-10-26. They are illustrative demo assets, not photographs of actual stock or manufacturer-approved product imagery. No third-party dealership photographs were copied.

JPEG files in `public/images/demo/` are optimized for inventory cards. Each type has its own image. They are reused across seeded trailers of that type; exact make, model, color and dimensions are illustrative. Real uploaded R2 photos must replace these on customer inventory. Keep the Demo image badge whenever a generated fallback is shown.
